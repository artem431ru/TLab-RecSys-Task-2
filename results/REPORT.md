# Отчёт: RL-дообучение GPT-2 для последовательных рекомендаций KION

## Постановка

Задача: сравнить next-item модель GPT-2 до/после RL, оценивая релевантность и прогнозируемую долю досмотра. Исследование проведено на **реальном KION** (не синтетических данных). В качестве токенов используются ID фильмов/сериалов.

## Данные и протокол

- Разбиение по `last_watch_dt`: train до **26.07.2021**, validation с 26.07 по 08.08 включительно, test с **09.08.2021**.
- Словарь из 600 самых частых объектов **только train**. Выборка 6000 пользователей с ≥3 train-событиями, случайная с фиксированным seed. Отбор пользователей не использует будущее.
- Train/validation/test примеров внутри выбранного каталога: 5000 / 300 / 300.
- Истории учитывают лишь фактически наблюдавшиеся события, предшествующие целевому по дате. На test доступны известные реальные события validation как история, но обучение на них не проводится.
- Метрики рекомендаций вычислены **только на событиях из top-600 train-каталога**, а не на полном KION. Невидимые объекты каталога не могут быть угаданы, поэтому полученные числа нельзя напрямую сравнивать с full-catalog RecSys.
- `last_watch_dt` в KION представляет агрегированную дату последнего просмотра для пары user-item. Это приближённая хронология, а не полный журнал сессий; при равных датах реальный порядок неизвестен.
- Тестовая выборка не применялась при подборе словаря, обучении и RL. Все настройки зафиксированы заранее. Дубликаты user-item исключаются природой агрегированного датасета.

## Модели

1. **GPT-2 SFT**: GPT2LMHeadModel с 2 Transformer-блоками, 4 attention-heads, hidden=64, контекст до 16 токенов; задача предсказания следующего item ID по реальной истории. Обучение 1 эпох, AdamW, LR=0.0005, CE.
2. **Reward model**: отдельная обучаемая нейросеть с embedding истории и объекта + MLP, sigmoid для прогноза `watched_pct/100` в [0,1]. Обучается 2 эпох на **наблюдаемых** парах из train. Полезность **ненаблюдавшихся** объектов из этих данных не известна. Результаты валидации: MAE=0.3301, RMSE=0.3721, n=300; теста: MAE=0.3553, RMSE=0.3918, n=300. MAE константного среднего train на test: 0.37852293333333337.
3. **RL**: REINFORCE, действие = выбранный item; награда из frozen reward model, штраф KL(π||π_SFT) с коэффициентом 0.1 и supervised-anchoring (CE) с коэффициентом 0.1. 40 RL-шагов, LR=5e-05. Запрещены уже просмотренные объекты (mask seen). **Два независимых старта из одной SFT:** reward = predicted watched_pct; reward = predicted watched_pct − 0.15 × train popularity, нормированная логарифмом.

## Релевантность и награда: Validation

| Модель | Recall@10 | NDCG@10 | Покрытие каталога@10 | RM reward@top1 |
|---|---:|---:|---:|---:|
| GPT-2 SFT | 0.24667 | 0.15248 | 0.04000 | 0.56610 |
| RL: raw watched_pct | 0.25000 | 0.15734 | 0.04000 | 0.57744 |
| RL: novelty penalty | 0.25000 | 0.14872 | 0.04000 | 0.59870 |

## Релевантность и награда: Test

| Модель | Recall@10 | NDCG@10 | Покрытие каталога@10 | RM reward@top1 |
|---|---:|---:|---:|---:|
| GPT-2 SFT | 0.19667 | 0.12950 | 0.04167 | 0.57010 |
| RL: raw watched_pct | 0.19333 | 0.12434 | 0.04000 | 0.57617 |
| RL: novelty penalty | 0.19667 | 0.12808 | 0.04167 | 0.59628 |

Recall@10 и NDCG@10 оцениваются на каждом следующем реально просмотренном объекте. При одном релевантном объекте на запрос Recall@10 совпадает с HitRate@10. `RM reward@top1` — средняя **предсказанная**, а не реальная оценка реакции на top-1 рекомендацию.

### Изменения по сравнению с SFT на Test

- **RL: raw watched_pct:** ΔNDCG@10 = -0.00516; ΔRecall@10 = -0.00334; ΔRM reward = +0.00607.
- **RL: novelty penalty:** ΔNDCG@10 = -0.00142; ΔRecall@10 = +0.00000; ΔRM reward = +0.02618.

Файлы `results/metrics.json`, `results/rl_trace.json` содержат полный набор результатов, включая coverage каталога и концентрацию популярности.

## Генерация 5 шагов

Здесь каждую собственную рекомендацию добавляем в историю как будто пользователь её выбрал. Это **симуляция, а не наблюдение**.

| Модель | RM reward шаги 1→5 |
|---|---|
| GPT-2 SFT | 0.576, 0.561, 0.600, 0.464, 0.367 |
| RL: raw watched_pct | 0.584, 0.575, 0.611, 0.556, 0.435 |
| RL: novelty penalty | 0.607, 0.658, 0.532, 0.522, 0.435 |

Условия оценки после первого шага изменяются: модель обучалась на настоящих историях, а получает собственные гипотетические действия. В отсутствие пользовательской модели и реальных ответов нельзя интерпретировать пятишаговые значения как доказанное долгосрочное улучшение.

## Компромисс и ограничения

- **RL: raw watched_pct:** ΔNDCG@10 = -0.00516; ΔRecall@10 = -0.00334; ΔRM reward = +0.00607.
- **RL: novelty penalty:** ΔNDCG@10 = -0.00142; ΔRecall@10 = +0.00000; ΔRM reward = +0.02618.

Повышение модельной награды не доказывает рост удовлетворённости пользователей. Выводы ограничены офлайн-наблюдениями и малой экспериментальной выборкой. `watched_pct` может давать смещение к коротким объектам и просмотрам уже вовлечённых пользователей, а learned reward можно эксплуатировать в областях без достоверной разметки. Отсутствуют impression logs и корректные propensity scores. **Контрфактическую награду и retention офлайн подтвердить нельзя.** Для проверки возвращаемости требуются последовательные реальные пользовательские сессии с датами повторных визитов и A/B-тест.

Обратим внимание на концентрацию рекомендаций: покрытие каталога и доля самого популярного item в рекомендациях указаны в `metrics.json`. Низкое покрытие или растущая концентрация после RL свидетельствует о коллапсе разнообразия даже при росте predicted reward.

## Воспроизведение

```powershell
pip install -r requirements.txt
python run_experiment.py --data "../recsys_research/data/interactions.csv" --out results
```

Для запуска с более широкой выборкой: `python run_experiment.py --data <path/to/interactions.csv> --users 15000 --items 1000 --max-train 20000 --max-eval 1000 --epochs 2 --rl-steps 120`.

Случайность фиксирована `seed=42`. Устройство: автоматический выбор CUDA/CPU, общее время запуска: 17.6 сек. Получение KION: https://github.com/irsafilo/KION_DATASET. Экспериментальная среда и версии зависимостей — в `requirements.txt`; аппаратная конфигурация влияет на скорость и незначительно на численные результаты.
